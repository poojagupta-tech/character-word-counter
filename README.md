# Character & Word Counter

A simple web application built using HTML, CSS, and JavaScript to count characters and words entered by the user.

## Features

- Count total characters.
- Count total words.
- Handle empty text correctly.
- Simple dark-themed user interface.
- Display results by clicking the Submit button.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `count.html` - HTML structure
- `count.css` - Styling and layout
- `count.js` - Character and word counting logic

## How to Run

1. Clone or download this repository.
2. Open the folder in VS Code.
3. Open `count.html` using Live Server.
4. Enter text and click Submit to see the results.

## Learning Outcomes

This project helped me practice DOM manipulation, event listeners, JavaScript string methods, and basic text processing.
